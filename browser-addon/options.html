Pi Light browser bridge

Run /browser-connect in Pi. The URL, token and controlled tabs are kept in extension session storage only so the add-on can resume after the browser stops its idle background worker. Disconnect clears them.

Once connected, Pi can open its own background tabs (grouped as "pi"); they close when Pi disconnects unless Pi asked to keep them. Click the toolbar button on one of your HTTP(S) tabs to also let Pi use it; that tab stays on its origin, and clicking again unbinds it. Pi never closes tabs it did not open.

Control uses the browser debugger, so the browser shows a "debugging this browser" bar while a tab is controlled; cancelling it releases control. Pi can read visible text, the accessibility tree, screenshots and recent console/network entries (no headers or URL queries), send real clicks and keys, and run JavaScript in the page. Pi asks you locally before every click, fill, key press, navigation, script, tab open or tab close, and before reading console text. Pages can still contain private data and malicious instructions; this is not secret isolation.
